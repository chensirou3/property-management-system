# 单项目网页首启改造与验收

日期：2026-09-03  
版本：`v0.1.0-internal-rc.2`

## 1. 交付模型

面向物业项目的默认交付模型为“一套部署、一个 MySQL 数据库、一个启用项目”。业务使用者不再通过 `.env` 或源码创建管理员：全新数据库第一次打开管理端时进入一次性初始化页面，在网页内填写企业、项目和首个管理员信息。

`.env` 只保存 MySQL、Redis、JWT、回调验签和端口等基础设施配置。Windows 双击 `启动物业管理系统.cmd` 后，`启动物业管理系统.ps1` 会在 `.env` 不存在时生成独立随机技术密钥，并启动、等待和打开系统；它不会生成或输出业务账号密码。

## 2. 首次配置流程

1. 全新数据库执行 Flyway V1—V23，共 91 张表；V23 创建唯一的 `system_setup` 行，初始状态为未初始化。
2. 前端启动时调用 `GET /api/v1/setup/status`。未初始化时，任何业务路由都会转到 `/setup`。
3. 使用者填写物业企业名称、项目名称、管理员姓名、登录账号、登录密码和确认密码，并确认单项目数据边界。
4. `POST /api/v1/setup/initialize` 锁定 `system_setup` 单例行，再次确认初始化状态和 `sys_user` 账号总数。
5. 同一事务中完成企业/项目命名、只保留一个启用项目、创建首个 `PLATFORM_ADMIN`、授予唯一项目范围、写入初始化状态和审计事件。
6. 前端使用刚设置的账号自动登录并进入首个有权页面。
7. 以后访问 `/setup` 会转到登录页或首页；重复或并发初始化返回 `409 SETUP_ALREADY_COMPLETED`。

## 3. 单项目约束

- 首次配置会把主项目设为 `ACTIVE`，其他合成隔离项目设为 `INACTIVE`，不物理删除测试证据。
- 项目列表默认只返回启用项目，顶部在只有一个项目时显示固定项目名称，不显示选择器。
- “小区档案”允许编辑当前项目资料，但网页不提供新增或停用项目按钮。
- 后端独立拒绝新增第二个项目（`409 SINGLE_PROJECT_LIMIT`）以及停用当前唯一项目（`409 SINGLE_PROJECT_REQUIRED`），不能靠修改前端请求绕过。
- 数据迁移样例中的 `PROJECT` 只映射到当前项目，不创建第二个项目。

## 4. 账号与密码

- 首个管理员由接收人在首次配置页自行设置，密码不进入交付 ZIP、文档、源码或 `.env`。
- 密码长度必须为 12—200 字符，并同时包含大写字母、小写字母、数字和符号，且不能包含完整登录账号。
- 后续账号在“企业管理 → 账号管理”中创建、停用、分配角色、重置密码；普通新账号仍执行首次改密机制。
- 账号登录继续受失败次数、时间窗和锁定时间限制。
- 环境变量 bootstrap 只保留给自动化和受控高级部署，默认关闭；已有数据库升级到 V23 时只会标记为已初始化，不会开放第二次首启。

## 5. 数据边界

网页填写真实企业/项目名称不代表内置合成数据已变成真实数据。交付版保留合成资产、客户、费用、账务、仪表、报表和模拟外部通道，用于可重复验收。正式使用前，接收方应使用迁移中心按授权数据执行 Raw、隔离、规范化、暂存、审批、生产写入、对账和可逆回滚流程。

支付、发票、银行、IoT、访客门禁和 Java110 仍为模拟或禁用模式，不得以网页首启完成为由描述成生产接通。

## 6. 安全设计

- 初始化接口只在数据库没有任何账号且 `system_setup.initialized=false` 时可用。
- 数据库行锁和单例主键阻止双击、并发请求或两个浏览器同时创建首个管理员。
- 初始化的企业、项目、账号、角色、范围、状态和审计在同一数据库事务中提交；任何一步失败都会整体回滚。
- 本地 Compose 的 Web、API、MySQL 和 Redis 端口默认只绑定 `127.0.0.1`，降低尚未初始化时被局域网抢占的风险。
- `GET /setup/status` 不返回账号、密码、哈希、令牌或基础设施秘密。
- 初始化审计事件使用 `system:initialize`，包含部署模式及企业/项目名称，不记录密码。

## 7. 自动验收项

- Java 编译与容器构建；
- 单元测试 39 项通过；
- 真实 MySQL 8.4 空库迁移 V1—V23、91 张表；
- 真实 MySQL 首次初始化、重复初始化 409、登录、单项目范围、默认项目列表和初始化审计；
- 前端 TypeScript/生产构建；
- Vitest 15 个文件、53 项测试；
- 49 页验收卡和 OpenAPI 快照/生成类型一致；
- 浏览器实际检查 `/setup` 路由、页面布局、所有输入项、确认开关、按钮状态，以及完成初始化后自动关闭入口。
