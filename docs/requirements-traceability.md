## G2 页面原语与验收体系证据

| 退出条件 | 证据 | 结果 |
|---|---|---|
| 49 页都有可追踪骨架 | `src/config/page-catalog.json` 恰好 49 项；8 个菜单组恰好 49 个目标路由；每项含目标路径、波次、类型、查询、列、权限、操作、状态和来源 | 已验证 |
| 49 页都有验收卡 | `docs/page-acceptance-cards.md` 由目录确定性生成；`pages:acceptance:check` 防止手工漂移 | 已验证 |
| 共享能力不是占位弹窗 | `QueryPanel`、`DataGrid`、`TreeWorkspace`、`BatchActionBar`、`TaskDrawer`、`MoneyCell`、`StatusTag`；CSV 导入/导出、打印、取消/重试/部分失败均可运行 | 已验证 |
| 复杂页面没有强塞万能 CRUD | 路由按 specialized / schema / capability、tree / report / external 等实现类型分派；目录测试禁止 `generic-crud` | 已验证 |
| API 契约不漂移 | 提交版 OpenAPI JSON、生成 TypeScript、前端静态检查、运行中检查和 Spring 集成测试五点闭环 | 已验证 |
| 可查看视觉差异 | 49/49 路由烟雾；3 个视口 × 49 页 = 147 张结构基线，首次生成后纯比对通过；另有 G1 6 张登录/壳层基线 | 已验证 |

G2 的“已验证”仅对应总方案第 7 节的页面原语与验收体系退出条件。目录中仍使用结构演练数据的页面会明确标识合成/脱敏和后续 Goal 波次；不得据此把 49 页标记为 L2/L3 全部完成。
