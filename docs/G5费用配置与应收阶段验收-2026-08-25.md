## 2. 已交付能力

### 2.1 费用配置

- 费用定义包含类型/分类、启停、会计科目、预收科目、税务分类、税率、币种、小数位、舍入方式、滞纳金和临时费用许可；
- 费用标准包含资产类型、计费周期、计算基础和分摊规则；标准版本独立追加，保存单价、最小/最大金额、生效区间、发布人和发布时间；
- 同一标准的 ACTIVE 版本区间不得重叠，边界日期按闭区间处理；
- 分配目标支持 ASSET 和 METER，保存标准、目标、系数、来源和生效区间；
- 批量分配必须先预览命中、冲突和可写数量；同请求可重放，重叠区间拒绝；取消通过截断有效期和记录原因保留历史；
- 定义、标准、版本和分配变更写入 `fee_configuration_event`，不通过覆盖历史配置实现“更新”。

### 2.2 应收计算与生成

- 周期计算支持 `BUILDING_AREA`、`USABLE_AREA`、`FIXED`、`METER_USAGE`；
- 计算顺序包含计费基础、单价、分配系数、最小/最大金额、定义级小数位和 `HALF_UP`/`HALF_EVEN`/`DOWN`/`UP`；
- 预览不落账，返回资产、客户、定义、标准版本、分配、公式参数、精度、舍入、金额、行校验值和整批 SHA-256；
- 周期任务与临时任务保存完整请求 JSON 和请求 SHA-256，在受控异步执行器中逐行落账；
- `Idempotency-Key` 同键同请求返回原任务，同键不同请求返回 409；
- 周期账单以项目、资产、账期形成数据库唯一键，既有不同配置账单返回 `PERIODIC_BILL_CONFIGURATION_CONFLICT`，不会覆盖或追加第二张；
- 临时应收使用独立请求模型，只允许 `temporary_allowed=true` 的启用定义，不复用周期分配规则；
- 每个任务保留逐行 GENERATED/SKIPPED/FAILED、错误代码/详情、账单引用以及三项配置—应收—账单对账；
- 账单和明细保留定义、版本、分配、公式、精度、舍入和完整快照校验值，配置更新后历史金额与证据不漂移。
