# 安全设计与检查

## 已实施控制

- BCrypt cost 12 保存密码；JWT 密钥必须由环境变量提供且长度至少 32 字符。
- 新密码至少 12 位并包含大小写字母、数字和符号，不能包含完整账号名，也不能与当前密码相同。
- IAM 新建账号首次登录必须改密；首次改密前服务端只允许读取本人信息、改密或撤销会话，不能绕过前端访问业务 API。
- JWT 包含角色、权限、项目范围和会话版本；账号、密码或角色权限变化会递增服务端会话版本，使旧令牌即时失效。
- 登录失败按账号哈希和来源 IP 哈希进行窗口计数和临时锁定；成功、失败、限流均写审计，但不保存原始账号或 IP。
- 后端每个业务入口再次校验权限和 `communityId`；`iam:read` 与 `iam:write` 在页面按钮和服务端分别控制。
- 启用账号的人员、企业角色和项目范围必须属于同一企业；停用角色/组织/岗位/人员前检查启用引用，避免通过错配或悬挂授权绕过边界。
- 会话令牌仅放在 `sessionStorage`，不写入 URL、日志或持久本地筛选条件。
- CORS 仅允许本地开发源；API 无服务端会话，CSRF 面收窄。
- Nginx/API 返回 `nosniff`、拒绝 frame、无 referrer、Permissions Policy；生产 Web 增加 CSP。
- 列表排序字段和资源名使用后端白名单，SQL 参数全部绑定。
- 乐观锁防止静默覆盖；账单和计量来源使用数据库唯一/检查约束。
- 财务写接口使用幂等键；成功流水只允许冲正。
- 迁移中心分别要求 `migration:read/import/write/export`；项目范围在每个批次 API 重验，审批与回滚额外要求 `PLATFORM_ADMIN`，写入使用批次版本锁。
- 迁移只接受受控资源和服务端参数绑定，不接受数据库连接串、明文数据库密码、任意表名或 SQL；回滚凭证只向具备写权限的登录人返回并使用常量时间比较。
- 来源 SHA-256、逐行 SHA-256、映射版本、审核人、状态事件、生产变更和回滚原因持久化；错误行不会进入生产层。
- 日志和错误不返回堆栈、密码、JWT、数据库连接秘密或原始个人信息。
- 前端 `npm audit` 当前为 0 漏洞；Axios、ECharts、Vite、Vitest 和 Happy DOM 已升级到修复版本。

## 上线前仍需外部完成

- 使用正式秘密管理器、TLS 终止、WAF/限流、集中日志和告警。
- 本地 bootstrap 管理员的初始密码轮换、生产 MFA、边缘 WAF/分布式限流、集中安全告警。
- 数据库账号最小权限、备份加密、恢复演练和保留策略。
- 真实支付/发票/IoT 接入前做供应商签名、重放防护、回调验签和独立渗透测试。
- 对真实住户数据制定分类分级、脱敏、导出审批和数据保留/删除流程。

本仓库只含合成数据和示例变量，不包含目标站账号、Cookie、令牌或真实住户资料。
