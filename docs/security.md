# 安全设计与检查

## 已实施控制

- BCrypt cost 12 保存密码；JWT 密钥必须由环境变量提供且长度至少 32 字符。
- JWT 包含角色、权限和项目范围；后端每个业务入口再次校验权限和 `communityId`。
- 会话令牌仅放在 `sessionStorage`，不写入 URL、日志或持久本地筛选条件。
- CORS 仅允许本地开发源；API 无服务端会话，CSRF 面收窄。
- Nginx/API 返回 `nosniff`、拒绝 frame、无 referrer、Permissions Policy；生产 Web 增加 CSP。
- 列表排序字段和资源名使用后端白名单，SQL 参数全部绑定。
- 乐观锁防止静默覆盖；账单和计量来源使用数据库唯一/检查约束。
- 财务写接口使用幂等键；成功流水只允许冲正。
- 日志和错误不返回堆栈、密码、JWT、数据库连接秘密或原始个人信息。
- 前端 `npm audit` 当前为 0 漏洞；Axios、ECharts、Vite、Vitest 和 Happy DOM 已升级到修复版本。

## 上线前仍需外部完成

- 使用正式秘密管理器、TLS 终止、WAF/限流、集中日志和告警。
- 管理员首次登录强制改密、MFA、登录失败节流和账户锁定。
- 数据库账号最小权限、备份加密、恢复演练和保留策略。
- 真实支付/发票/IoT 接入前做供应商签名、重放防护、回调验签和独立渗透测试。
- 对真实住户数据制定分类分级、脱敏、导出审批和数据保留/删除流程。

本仓库只含合成数据和示例变量，不包含目标站账号、Cookie、令牌或真实住户资料。
