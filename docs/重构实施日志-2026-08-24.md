## G1 批次 2：登录安全、会话撤销与权限写控制

执行日期：2026-08-24

### 本批完成

1. 新增 Flyway V9，为账号增加 `session_version`、`password_changed_at`，并建立 `auth_login_guard`；运行库升级到 V9，共 55 张表。
2. 登录失败按账号和来源 IP 的 SHA-256 摘要计数，支持可配置时间窗、失败阈值和锁定时间；登录成功、失败和限流均写 `audit_event`，测试确认不保存原始账号或 IP。
3. JWT 增加会话版本声明，每个 Bearer 请求都会核对账号启用状态和数据库会话版本。账号、密码、角色权限变化及主动撤销会话都会让旧令牌即时失效。
4. 增加强密码策略：至少 12 位，必须含大小写字母、数字和符号，不能包含完整账号名或复用当前密码；IAM 创建和重置密码统一执行该策略。
5. 新账号固定标记首次改密；服务端在改密前仅允许 `/auth/me`、`/auth/change-password` 和 `/auth/sessions:revoke`，防止绕过前端访问业务 API。改密成功返回新令牌。
6. 管理端增加独立首次改密页和路由强制跳转，登录后根据服务端标识进入改密流程。
7. 页面按钮按 `iam:write` 控制，同时保留服务端 `iam:write` 强制校验。只读角色可查看 IAM，不能看到新增、编辑和重置密码操作，直接写 API 返回 `403 PERMISSION_DENIED`。
8. OpenAPI 类型已按运行中 V9 API 重新生成；Compose 暴露三项登录保护参数，示例环境文件和运行/安全/API 文档已同步。
9. 形成 ADR-007：G1 退出前以独立提交把 Spring Boot 2.7.18 迁移到受支持的 3.5.x，不把框架升级与业务迁移混在同一提交。
