# 物业管理平台（PMS3 独立复刻工程）

本工程在不修改上游 Java110 源码的前提下，独立实现物业管理 PC 端的 UI、基础档案、费用配置、收费账务和抄表基础闭环。

当前状态：正在按 G0—G10 完整 Goal 持续重构。G0 基线、G1 企业组织权限、G2 页面原语与验收体系和 G3 基础档案纵向闭环已经完成本地退出门禁，下一阶段为 G4 迁移中心；不得把阶段性内部验收描述为全量功能复刻或生产等价。权威范围、证据和验收标准见：

## 技术基线

- Web：Vue 3、TypeScript、Element Plus、Vite；
- API：Java 17、Spring Boot 3.5；
- 数据：MySQL 8、Flyway、Redis；
- 本地运行：Docker Compose；
- 外部支付、发票和 IoT：默认模拟适配器。

## 安全边界

- 不包含目标站凭据、Cookie、令牌或真实住户数据；
- 合成版“优山美地”只保持数量和关系特征；
- 模拟通道不代表生产支付、发票或设备能力；
- 财务成功流水不可物理删除，冲正使用反向流水。

## 已实现范围

- 登录、RBAC、双项目数据范围、企业、组织、岗位、人员、账号和角色权限管理；
- 小区、网格、楼栋、单元、房屋、客户、关系、车位、车辆、仪表等基础档案，以及资产树、客户关系时间线、产权变更和导入预校验；
- 费用定义、版本化标准、资产分配、应收试算和幂等账单生成；
- 收银台、支付模拟、账单、欠费、预收、押金、收据、发票模拟和冲正；
- 抄表批次、读数、IoT 模拟、公摊试算/应用、审核、换表和计量费用；
- 49 页机器可读目录、逐页验收卡、精确路由/权限、查询与列模型、8 类状态定义；
- 查询、表格、树、批量、金额、状态和任务中心共享原语，浏览器内可运行的 CSV 导入/导出与打印基础；
- 56 张表、11 个 Flyway 迁移、65 个权限、两个隔离的合成项目、提交版 OpenAPI 契约与类型漂移门禁；
- 49/49 路由烟雾、三个目标视口 147 张页面像素基线，以及 Maven/Vitest/Playwright 自动化。
