# 物业管理系统

本工程在不修改上游 Java110 源码的前提下，独立实现物业管理 PC 端的 UI、基础档案、费用配置、收费账务和抄表基础闭环。

当前状态：G0—G10 内部重构与最终验收已完成，当前为 `v0.1.0-internal-rc.2` 发布候选。49 个范围页面全部达到 L1/L2，高置信 IAM、基础档案与费用配置页面达到 L3；不得把内部模拟适配、合成数据或 RC 标签描述为真实生产接入。权威范围、证据和验收标准见：

- `../PMS3目标系统调查/PMS3物业核心复刻工程Goal计划与实施方案.md`
- `docs/PMS3完整重构Goal执行总方案-2026-08-24.md`
- `docs/requirements-traceability.md`

## 技术基线

- Web：Vue 3、TypeScript、Element Plus、Vite；
- API：Java 17、Spring Boot 3.5；
- 数据：加固版 MySQL 8.4、Flyway 11.20、Redis 7.4；
- 本地运行：Docker Compose；
- 外部支付、发票、银行和 IoT：默认模拟适配器；Java110 明确禁用。

## 安全边界

- 不包含目标站凭据、Cookie、令牌或真实住户数据；
- 合成版“优山美地”只保持数量和关系特征；
- 模拟通道不代表生产支付、发票或设备能力；
- 财务成功流水不可物理删除，冲正使用反向流水。

## 已实现范围
