# 物业管理平台（PMS3 独立复刻工程）

本工程在不修改上游 Java110 源码的前提下，独立实现物业管理 PC 端的 UI、基础档案、费用配置、收费账务和抄表基础闭环。

当前状态：核心范围已实现并完成真实本地环境验收；生产等价仍取决于真实费用、公摊、支付、发票和 IoT 资料。权威范围、证据和验收标准见：

- `../PMS3目标系统调查/PMS3物业核心复刻工程Goal计划与实施方案.md`
- `docs/requirements-traceability.md`

## 技术基线

- Web：Vue 3、TypeScript、Element Plus、Vite；
- API：Java 17、Spring Boot 2.7；
- 数据：MySQL 8、Flyway、Redis；
- 本地运行：Docker Compose；
- 外部支付、发票和 IoT：默认模拟适配器。

## 安全边界

- 不包含目标站凭据、Cookie、令牌或真实住户数据；
- 合成版“优山美地”只保持数量和关系特征；
- 模拟通道不代表生产支付、发票或设备能力；
- 财务成功流水不可物理删除，冲正使用反向流水。

## 已实现范围

- 登录、RBAC、项目数据范围、菜单布局、查询筛选、通用增改与软停用；
- 小区、楼栋、单元、房屋、客户、关系、车位、车辆、仪表等基础档案；
- 费用定义、版本化标准、资产分配、应收试算和幂等账单生成；
- 收银台、支付模拟、账单、欠费、预收、押金、收据、发票模拟和冲正；
- 抄表批次、读数、IoT 模拟、公摊试算/应用、审核、换表和计量费用；
- 50 张表、7 个 Flyway 迁移、合成优山美地数据、OpenAPI 生成类型、Maven/Vitest/Playwright 测试。
